## 中文

### 如何参与

1. **Fork** 本仓库
2. 创建功能分支：`git checkout -b feature/amazing-feature`
3. 提交更改：`git commit -m '添加某功能'`
4. 推送：`git push origin feature/amazing-feature`
5. 发起 **Pull Request**

### 代码规范

- 语言：Kotlin，遵循 [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html)
- UI：Jetpack Compose + Material 3
- 架构：MVVM（ViewModel + StateFlow）
- 测试：新功能建议附带单元测试（`app/src/test/`）
- 提交信息：中文或英文均可，简明描述变更内容

### Issue 规范

- **Bug 报告**：附上复现步骤、App 版本、Android 版本
- **功能建议**：描述使用场景和期望行为

### 许可证

提交代码即表示同意以 [Apache 2.0](LICENSE) 许可证发布。

## English

### How to Contribute

1. **Fork** this repository
2. Create a feature branch: `git checkout -b feature/amazing-feature`
3. Commit changes: `git commit -m 'Add amazing feature'`
4. Push: `git push origin feature/amazing-feature`
5. Open a **Pull Request**

### Code Style

- Language: Kotlin, follow [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html)
- UI: Jetpack Compose + Material 3
- Architecture: MVVM (ViewModel + StateFlow)
- Tests: Unit tests recommended for new features (`app/src/test/`)
- Commit messages: Chinese or English, concise description

### Issue Guidelines

- **Bug reports**: Include reproduction steps, app version, Android version
- **Feature requests**: Describe use case and expected behavior

### License

By submitting code, you agree to license it under [Apache 2.0](LICENSE).
